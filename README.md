# joaomdsferro/tap

Homebrew tap for apps by João Ferro.

```sh
brew install --cask joaomdsferro/tap/omega-notch
```

| Cask | App |
|---|---|
| `omega-notch` | [Omega Notch](https://github.com/joaomdsferro/omega-notch): your AI coding tools' usage limits and live sessions, in a notch (macOS 14+) |

Update with `brew upgrade`. Remove with `brew uninstall --cask omega-notch`, or add `--zap` to delete its settings too.
